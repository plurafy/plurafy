Challenge

Section titled “Challenge”

You need to create a function that yields values one at a time on demand instead of returning all at once. How can you create an infinite sequence that’s memory efficient?

Explanation

Section titled “Explanation”

Generators are functions that can be paused and resumed, yielding values one at a time. They implement the iterator protocol, enabling lazy evaluation and memory-efficient iteration.

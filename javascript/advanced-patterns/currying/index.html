Function Currying and Partial Application

Creating specialized functions through currying and partial application

Challenge

Section titled “Challenge”

You have utility functions that take multiple parameters. You frequently call them with some parameters pre-filled. How can you create specialized versions without writing wrapper functions?

Explanation

Section titled “Explanation”

Currying transforms a function that takes multiple arguments into a sequence of functions that each take one argument. Partial application fills in some arguments to create a new function.

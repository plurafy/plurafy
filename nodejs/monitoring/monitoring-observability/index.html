Three Pillars of Observability

Section titled “Three Pillars of Observability”

Metrics: Quantitative measurements

  • Throughput, latency, error rates
  • Resource utilization
  • Custom business metrics

Logs: Event records

  • Request logs
  • Error logs
  • Application logs

Traces: Request flow

  • Distributed tracing
  • Request path
  • Latency breakdown
